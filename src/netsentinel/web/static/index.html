Incidents as they happen

    How it decides

    رحلة كل اتصال من الحزمة الخام إلى التنبيه. الخطوتان المعلَّمتان باللون السماوي هما تعلّم الآلة.

    1. capture

      Packets become connections

      نجمع الحزم حسب (المصدر، الهدف، المنفذ، البروتوكول) ونحدّد حالة TCP لكل اتصال: SF مكتمل، S0 بلا رد، REJ مرفوض.

    2. features

      28 numbers per connection

      الحجم والمدة والحالة، و"ذاكرة" الماضي القريب: كم اتصالاً لنفس الهدف خلال آخر ثانيتين؟ كم منها فشل؟

    3. machine learning — supervised

      Classifier names known attacks

      شبكة عصبية MLP (وRandom Forest للملف الكامل) تدرّبت على 100 ألف اتصال مُسمّى، فتعطي: DoS أو Probe أو R2L أو U2R أو طبيعي، مع نسبة ثقة.

    4. machine learning — unsupervised

      Autoencoder knows "normal"

      شبكة Autoencoder تدرّبت على الحركة الطبيعية فقط: تضغط الاتصال ثم تعيد بناءه. إذا فشلت في إعادة بنائه فهو غريب — حتى لو لم يُرَ هجوم مثله قط.

    5. decision

      Fuse, explain, alert

      إذا قال المصنِّف "هجوم" نعتمد تسميته. إذا قال "طبيعي" والـ Autoencoder قال "غريب" ← Unknown-Anomaly. ثم نشرح السبب بالعربية.
